# precog-esgf-intake

**precog-esgf-intake** provides tools for discovering, accessing, and working
with ESGF climate-model datasets through Intake.

It is designed for reproducible workflows involving CMIP6 and related Earth-system
model data, including catalogue construction, dataset discovery, data access, and
integration with scientific Python analysis pipelines.

## Why this package?

- Provide a consistent interface to ESGF data through Intake.
- Support reproducible climate-model data workflows.
- Make common CMIP6 discovery and access patterns easier.
- Integrate cleanly with `xarray`, `pandas`, and scientific Python tooling.
